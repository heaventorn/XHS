# 小红书关键词帖子采集工具

基于 Playwright 的小红书关键词搜索帖子采集脚本，自动搜索指定关键词，采集帖子的**账号名、帖子标题、帖子链接、发布时间**，并输出到 Excel。

## 功能

- 自动搜索多个关键词，采集帖子信息（账号名 / 标题 / 链接 / 发布时间）
- 自动去重（同一帖子只保留一条）
- 可选过滤：只保留两年内发布的帖子
- 深度反检测：
  - Canvas / WebGL / Audio 指纹保护（基于 seed 的稳定伪随机）
  - 人类化鼠标移动、随机滚动、打字节奏
  - 随机帖子浏览交互，模拟真实用户
  - 分层随机延迟（页面加载 / 搜索后 / 滚动 / 关键词之间）

## 依赖安装

```bash
pip install playwright openpyxl -i https://pypi.tuna.tsinghua.edu.cn/simple
```

脚本使用系统已安装的 Chrome 或 Edge，无需额外下载浏览器。

## 使用方法

1. 编辑 `xhs_keyword_scraper.py` 顶部的**配置区**：
   - `KEYWORDS`：要搜索的关键词列表
   - `MAX_PER_KEYWORD`：每个关键词最多采集多少条
   - `FILTER_WITHIN_TWO_YEARS`：是否只采集两年内的帖子
2. 运行：

```bash
python xhs_keyword_scraper.py
```

3. 首次运行会弹出浏览器，**手动登录小红书**（扫码或手机号）
4. 登录后脚本自动执行，完成后 Excel 生成在桌面

## 输出文件

`桌面/小红书关键词采集_年月日_时分秒.xlsx`

包含列：序号、搜索关键词、账号名字、帖子标题、帖子链接、作者主页、发布时间

## 注意事项

- 运行过程中不要关闭浏览器窗口
- 如遇验证码，手动完成后脚本会继续
- 建议不要频繁运行，避免触发风控
- 请遵守小红书平台规则及相关法律法规，合理合规使用
