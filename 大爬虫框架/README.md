# 大爬虫框架 · 多渠道找 CFO / 融资负责人

一个面向**产业基金投资人**的合规爬虫框架：多渠道免费搜集 A–C 轮未上市公司的融资信息与
FA / CFO 联系方式线索。小红书已作为第一个采集器接入，企查查（直接拿电话/邮箱）、知乎、
B 站等采集器按同一模式扩展。

> 由原单文件小红书爬虫重构而来：公共能力（双密码验证 / 反爬伪装 / 人味行为 / 黑名单 /
> 通用提取 / 双层 Excel 落盘）抽离到 `core/` 供所有平台复用，小红书瘦身为
> `platforms/xhs.py` 成为第一个采集器。

---

## 目录结构

```
大爬虫框架/
├── run.py                # 主入口：双密码验证 → 跑启用的采集器 → 双层 Excel 落盘
├── 启动框架.bat          # Windows 双击启动（含密码弹窗）
├── config/
│   └── settings.py       # 密码、输出路径、平台开关（集中配置）
├── core/                 # ★ 公共核心层（所有平台共用）
│   ├── auth.py           # 双密码验证（Argon2id 16MB 低内存档，适合办公电脑）
│   ├── stealth.py        # 深度反爬注入（Canvas/WebGL/Audio 指纹保护等）
│   ├── humanize.py       # 人味行为：鼠标轨迹、随机滚动、打字节奏、分层延迟
│   ├── network.py        # Referer 链伪装、资源拦截、UA-CH 预热
│   ├── extract.py        # 时间 / URL / ID / 作者名提取
│   ├── blacklist.py      # 账号黑名单 + 不相关内容关键词库
│   ├── storage.py        # ★ 双层 Excel 落盘（线索池 + 联系池）
│   └── browser.py        # 浏览器启动（优先系统 Chrome/Edge，持久化登录态）
└── platforms/            # 平台采集器（每个一个类，统一 .platform + run() 接口）
    └── xhs.py            # 小红书采集器（社交渠道 → 线索池）
```

## 快速开始

### 依赖安装

```bash
pip install playwright openpyxl argon2-cffi -i https://pypi.tuna.tsinghua.edu.cn/simple
```

脚本使用系统已安装的 Chrome / Edge，无需额外下载浏览器。

### 运行

**方式一：双击 `启动框架.bat`**（推荐，含密码验证弹窗）

**方式二：命令行**

```bash
python run.py
```

首次运行会弹出浏览器，**手动登录小红书**（扫码或手机号），登录成功后自动开始采集。

## 双密码验证机制

为保护家庭私人项目中的敏感数据（个人持仓、账号信息等），脚本采用**双密码验证**：

1. **手动访问密码**：每次启动弹窗输入（`config/settings.py` 中 `MASTER_PWD`）
2. **本地强密码**：存在本地 `pwd.key` 文件（**不上传 GitHub**，已被 `.gitignore` 忽略）

两者拼接后经 **Argon2id**（16MB 内存参数，办公电脑友好）哈希校验，均正确才放行。
即使源码公开，攻击者缺少本地 `pwd.key` 也无法通过验证。

|----|------|------|
| 关键词 / 每词上限 | `platforms/xhs.py` 顶部 | 小红书搜索词与采集量 |

## 扩展新平台

新增一个平台（如知乎 / 企查查）只需三步：

1. 在 `platforms/` 新建 `xxx.py`，定义一个类：
   ```python
   class XXXCrawler:
       platform = "知乎"
       def run(self, **kwargs):
           # 返回行列表（对齐 core.storage 字段）
           return rows
   ```
2. 伪装层全部从 `core` 导入（`humanize` / `network` / `stealth`），不重复造轮子。
3. 在 `config/settings.py` 的 `ENABLED_PLATFORMS` 打开开关，`run.py` 自动接入。

## 注意事项

- 运行过程中不要关闭浏览器窗口
- 如遇验证码 / 风控拦截，脚本会检测并等待，手动完成后自动继续
- 采集频率已刻意调低并随机化，但仍请合理控制运行次数，避免触发平台风控
- 请遵守各平台规则及相关法律法规，合理合规使用
- 本项目为家庭私人项目，`pwd.key` / 个人持仓等敏感文件仅存本地，不上传公开仓库
